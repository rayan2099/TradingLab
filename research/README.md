# TradingLab comprehensive knowledge extraction

This directory is the resumable, evidence-traceable research layer for the Telegram group
«احتراف المضاربات اللحظية ٩». It does not contain private images or media.

- `RESEARCH_PROGRESS.json` is the authoritative checkpoint.
- `MESSAGE_REVIEW_INDEX.jsonl` records what was actually reviewed.
- `CHART_CASES_DATASET.jsonl` distinguishes text-derived cases from visually reviewed charts.
- `TRADING_RULES_MASTER.json` contains codable rules and provenance.
- `UNRESOLVED_QUESTIONS.md` lists access and calibration gaps.

The prior `docs/CANDLES_VOLUME_RULES.md` remains preserved as the baseline. Its statement that
group text was read is not counted as visual chart review.
